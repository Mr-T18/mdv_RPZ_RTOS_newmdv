# mdv_RPZ_RTOS_newmdv
2026 new Motor Driver project for RP2040-zero
## 現在の機能
- セマフォを使用し，タスクごとに優先度をつけて割り込み処理を行う
- デュアルコアを使用し，0コアではcan通信割り込み，can受信，Control関数，Motor関数を動かし，
1コアではディスプレイ表示とデバッグ用シリアル表示(PC上)を行う．

## これから追加する機能
- モタドラ上でモータの回転方向の設定の切り替えを可能にする(Motor関数の中の変数だけ変えるか，全体的に変えるか)
- サブボタンを押したら，canIDおよび回転方向の設定画面になる
その間，can通信やモータ駆動は停止しており，安全のため，設定画面に入るタイミングでモータに停止命令を送る
